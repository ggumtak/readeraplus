# 이북 AI 사전

선택 → 검색 → AI에서 이북리더기는 가벼운 Claude 사전을, 일반 폰은 기존 ChatGPT를 사용한다. 둘 다 선택한 글에 ` 뜻`을 붙인다. 기기 판별이 아직 없으면 AI 탭을 열 때 비동기로 확인한다.

사이트: https://readeraplus-ai-dictionary.jinaoneday.chatgpt.site

## 사용

1. 사이트에 같은 ChatGPT 계정으로 로그인한다. 개인용 사이트이므로 첫 접근 때 로그인할 수 있다.
2. 메뉴 → Claude API 연결에서 Anthropic API 키를 한 번 입력한다. 서버에서 사용자별로 암호화해 보관한다. 앱과 URL에는 API 키가 없다.
3. 기본값은 Haiku 5.5 / 중간. 입력창의 모델 버튼에서 Sonnet 5.5·Opus 5.5, 낮음·중간·높음·엑스트라를 선택한다.
4. 앱 설정 → 사전·번역·검색 → 이북 AI 사전에서 주소를 바꿀 수 있다. 주소는 기기별 설정이며 백업으로 복사하지 않는다.

## 성능과 동작

- 첫 채팅 화면은 자체 HTML·CSS·JavaScript만 사용한다. 외부 폰트·음성 기능·애니메이션·클라이언트 프레임워크가 없다.
- 답변은 스트리밍하고 텍스트 화면 갱신은 500ms 단위로 묶는다. 첫 글과 마지막 결과는 즉시 반영한다.
- 선택한 글은 URL fragment의 `q`에 넣는다. 다른 선택은 같은 페이지에서 처리할 수 있다.
- 이북에서 다른 사전을 보고 있는 동안 AI를 미리 보내지 않는다. 일반 폰의 GPT 사전 미리 읽기는 유지한다.
- 대화 문맥은 짧게 제한하며 이 창에서 이어진다. 서버에는 대화를 저장하지 않는다.
- API 요청은 서버에서만 수행한다. 모델은 `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`, 엑스트라는 `xhigh`다.

사이트 소스는 Sites 프로젝트에서 관리한다. Claude API의 실제 첫 답변 속도와 이북 패널 반응은 실기기에서 확인해야 한다.
