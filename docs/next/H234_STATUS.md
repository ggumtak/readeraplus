## H3: 볼륨 키 방향
- 읽기 중 메뉴: 아래=다음 / 위=다음 / 넘기지 않음의 세 가지 선택.
- 전체 설정의 두 스위치와 설명은 현재 설정을 즉시 반영한다. 별도 키 동작이 있으면
  이유를 표시하고 방향 스위치를 비활성화한다.
- 볼륨 키의 다음·이전 지정은 양쪽 방향으로 정규화한다. 이전의 중복 페이지 지정은
  제거하며, 메뉴 등 다른 동작과 볼륨 외 키는 유지한다.
- 키 테스트와 지정 대화상자도 실제 매핑을 사용한다. 새 순수 회귀 6개 통과.
- CI 14d는 위 키로 다음 페이지가 표시되는지와 설정 변경 때 재배치가 없는지 확인한다.

## H4: 대화상자와 본문 크기
