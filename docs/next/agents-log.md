# Haiku 위임 기록

Haiku 서브에이전트에 맡긴 일이 메인의 총수고를 실제로 줄였는지 보는 표다(CLAUDE.md "Haiku 위임 기록"). 비교의
끝점은 Haiku가 답한 시점이 아니라, 메인이 그 근거로 다음 판단에 들어간 시점이다.

- **유형**: 같은 종류끼리 모아 본다(예: 호출 위치 수집, 여러 파일의 구조 조사, 테스트 실행·로그 발췌, 문서 발췌).
  단순 검색과 원인 분석을 한 유형으로 섞지 않는다.
- **확인**: 메인이 원문을 직접 열어 대조한 곳 수.
- **재검색**: 없음 / 검수(표본 확인) / 새 질문(결과를 보고 생긴 질문, Haiku 실패 아님) / 누락·오류(요청한 근거가 빠지거나
  틀림 = 위임의 재작업 비용).
- **판정**: 유지(확인만 하고 넘어감) / 애매 / 손해(메인이 같은 검색을 거의 다시 함).

같은 유형이 10줄쯤 쌓이면 유지·중단을 정한다. 누락·오류가 두 번 나온 유형은 바로 위임을 멈춘다. 검색어와 범위가
이미 정해진 짧은 검색은 위임하지 않고 메인이 직접 grep한다(기록 대상 아님).
