# SET 설정 화면 구현 결과 (2026-10-03)

PLAN §1.6.3·§4 "SET"과 K12의 설정 화면 작업을 마쳤다. 변경은 `ui/settings/`와 `SettingsFormatTest`에 한정된다.
문구·선택지·요약은 순수 객체 `R3Rows`와 `SettingsReset`(`SettingsLogic.kt`)에 모아 JVM에서 검사한다.

- **넘김·화면 설정(PageTurningPage)**
  - 섹션 순서: 넘기는 방식(첫 섹션) · 화면 터치 · 스와이프 · 길게 누르기 · 버튼 · 키 · 자동 넘김 · 책 끝 · 페이지 표시 · 상태 표시줄 · e-ink 화면.
  - 넘기는 방식:
    - 스크롤을 고르면 기기 종류가 아직 없을 때 `DeviceClass.probeAsync`를 시작한다.
    - 스크롤 움직임은 SCROLL에서만 보인다. 요약은 "자동 (이 기기: e-ink → 손을 떼면 이동)" 형식이다.
  - SCROLL에서는 스와이프로 넘김 요약이 "좌우로 밀면 한 화면씩"으로 바뀌고, 세로 스와이프는 `setRowEnabled(false)`로 꺼진다.
  - 페이지 표시:
    - 좌우 여백과 상하 여백은 스테퍼다. 값에 polite live region을 걸었다.
    - 두 스테퍼 아래에 공용 안내문을 둔다. 스테퍼와 안내문은 페이지 여백이 꺼지면 숨는다.
    - 그 아래는 페이지 나눔(A §4.4 선택지 문구) · 흑백 반전 · 페이지 여백 순이다.
  - 상태 표시줄:
    - 안내문, 슬롯 행 6개, 진행 막대가 있다.
    - 상태 표시 글자 크기는 글자가 있는 띠가 있을 때만 보인다.
    - A §2.7의 맞춤 안내문은 `StatusFit.fitsDp`로 판정한다. 페이지 여백이 꺼져 있으면 4 dp로 본다.
  - 볼륨 행의 토글 동기화를 고쳤다. 기존 코드가 `InkToggle`로 캐스트해서 실제 `EinkToggle`에는 반영되지 않았다.
- **설정(MainPage)**
  - 일반: 서재 보기 선택지에 N §10.2 설명 4개를 넣었다. 목록 넘기기를 새로 넣었다.
  - 읽기 설정: §1.6.3의 16행 순서다. 스와이프로 밝기 조절 요약은 SCROLL과 NONE 상태에 따라 바뀐다.
  - 밝기 행:
    - 기기 밝기 직접 조절은 권한이 없으면 대화상자 A를 띄운다. 이어서 권한 화면을 열고, 없으면 대화상자 C를 띄운다.
    - 돌아오면 `onResume`에서 IO로 canWrite와 verdict를 확인한다.
    - 리더를 나가면 원래 밝기로는 기기 밝기가 꺼져 있으면 비활성이다.
    - 밝기 방식 다시 확인은 IO에서 `setVerdict(UNKNOWN)`을 부른다. 기기 조명 설정 열기도 있다.
  - 인용문 색 표시: 자동 / 색 / 흑백 무늬. 22×14 dp `QuoteSwatch` 6개 띠와 안내문을 붙였다.
  - 설정 초기화(K12):
    - autoBackup, recordLookups, brightnessDevice, listPaging도 유지한다.
    - 읽기 설정은 40/40/40/40 여백, 줄 단위, 기본 슬롯으로 돌아간다.
    - 유지 항목은 대화상자 문구에 모두 적었다.
- **백업(BackupPage)**
  - 자동 백업 섹션: 토글과 권한별 요약이 있다.
  - 지금 자동 백업하기: `runNow(force)` 결과를 상태 줄에 보인다.
  - 자동 백업에서 복원: 후보 목록 → 기존 확인 → `restore` → 재시작 안내 순이다.
  - 자동 백업 파일 지우기: 권한에 따라 문구와 `others` 값이 달라진다. 개수는 IO에서 폴더 또는 MediaStore로 센다.
  - 개인정보 안내문에 단어장을 넣었다. N §11 병합 안내문은 [Δ] 문장까지 넣었다.
  - 수동 복원도 `InstallState.settleOffer`를 부른다.
- **정보(AboutPage)**
  - 최근 종료는 유지했다.
  - 조명 진단: `LightProbe.report` 줄을 IO에서 읽는다. 각 줄을 누르면 복사된다.
  - 변화 감지 30초: `Settings.System` ContentObserver로 바뀐 키를 "키 이전 → 이후"로 보인다. 변화가 있을 때만 다시 그려서 타이머 갱신이 없다.
- **사전 · 번역 · 웹 검색(LookupPage)**: 단어장 섹션에 찾아본 단어 기록, 단어장 열기(단어 탭), 단어장 비우기(개수 확인)가 있다.
- **polish 12**
  - `section()`의 구분선을 없앴다. 헤더 여백은 24/8이다.
  - 펼침 화살표(chevron)와 ▾는 모두 24 dp GRAY다.
  - `EinkToggle`의 꺼짐 상태는 꽉 찬 검은 손잡이다.
  - 비활성 행은 탭을 받지 않는다. TalkBack은 "사용 중지됨"으로 읽는다.

결정·차이:

- 스크롤 움직임 문구는 동결된 enum 라벨("손가락을 따라 이동", "손을 떼면 이동")을 따른다. S의 "부드럽게"는 쓰지 않는다.
- 기기 종류가 null(확인 전)이면 휴대폰으로 표시한다. 리더와 서재도 같은 규칙으로 판정한다.
- 모든 파일 접근 권한 행은 기능 유지를 위해 일반 섹션에 남겼다.
- 밝기 방식 다시 확인 요약은 UI_SPEC §4.6 문구를 따랐다. brightness.md §5.6 문구와 다르다.
- 기기 밝기 직접 조절을 끌 때 `DeviceLight.restore()`를 설정 화면에서 부르지 않는다. 리더가 앞에 없으므로 복원은 리더 쪽에서 처리한다.
- 자동 백업 복원 목록은 계약의 `findCandidates`를 그대로 쓴다. KDoc에는 다른 설치와 수동 백업만 있다.
  S §3.8 [Δ]는 이 설치의 파일도 포함하라고 하므로 DA-C에 요청했다.
